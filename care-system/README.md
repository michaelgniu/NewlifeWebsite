# 新生命教会 · 关怀探访系统

用 **Google 表格 + Apps Script + Gmail** 实现新人跟进的自动分配、提醒、升级与安排。
无需服务器、无托管费用；提醒通过 Gmail 发出。

## 一、流程概览

1. 新人来了 → 手动登记进「访客」表
2. **每周三上午** 系统给「待分配」访客自动分配一位同工，发邮件提醒周三/四致电欢迎
3. 同工联系后，点邮件里的链接填「探访反馈」→ 系统记录
4. **每周五上午** 若仍无反馈 → 二次提醒同工 **+ 通知探访负责人**接手
5. 来访满 4 次 → 基督徒按区域就近安排小组（通知组长）；慕道友加入福音群（通知福音负责人）
6. 首访满 4 周仍联系不上 → 自动移入「失联名单」，停止联系

## 二、安装步骤（约 15 分钟，一次性）

### 1. 新建 Google 表格
- 打开 https://sheets.google.com ，新建一个空白表格，命名如「关怀探访数据库」

### 2. 粘贴代码
- 菜单 **扩展程序 → Apps Script**
- 把仓库里的 `Code.gs` 全部内容贴进默认的 `Code.gs`
- 点 **＋ → HTML**，新建一个名为 **`Feedback`** 的文件（名字必须是 Feedback），把 `Feedback.html` 内容贴进去
- 保存（💾）

### 3. 初始化表格
- 在 Apps Script 顶部函数下拉选 **`setupSheet`**，点 **运行**
- 首次会要求授权，按提示允许（选你的 Google 账号 → 高级 → 转至项目 → 允许）
- 运行后回到表格，会看到「访客/跟进记录/同工/小组/设置」五个工作表

### 4. 填写基础数据
- **设置** 表：把「探访负责人邮箱」「福音事工负责人邮箱」改成真实邮箱
- **同工** 表：填探访同工（姓名、邮箱、可选负责区域、角色填「同工」或「负责人」、启用填 TRUE）
- **小组** 表：填各小组（组名、覆盖区域、负责人姓名/邮箱、聚会时间）

### 5. 部署为网页应用（同工反馈用）
- Apps Script 右上 **部署 → 新建部署 → 类型选「网页应用」**
- 执行身份：**我**；访问权限：**任何人**
- 部署 → 复制得到的网址（系统会自动在提醒邮件里带上此链接，无需手动填）

### 6. 安装定时触发器
- 函数下拉选 **`installTriggers`**，点 **运行**
- 完成后即启用：**周三9点分配、周五9点升级、每日8点检查**

## 三、日常使用

| 操作 | 怎么做 |
|---|---|
| 登记新人 | 在「访客」表加一行：姓名、电话、身份、区域、首次来访日期，**当前状态填「待分配」**，来访次数填 1 |
| 记录再次来访 | 每主日给到场的访客把「来访次数」+1（满 4 次系统自动安排） |
| 同工反馈 | 点提醒邮件里的链接填写，自动入库 |
| 查看失联 | 「访客」表中「当前状态」=失联 的即是 |

## 四、字段说明（访客表）

访客ID · 姓名 · 电话 · 邮箱 · 居住区域 · 身份（基督徒/慕道友/未知）· 首次来访日期 ·
来访次数 · 当前状态（待分配/跟进中/已联系/已安排小组/福音群/失联）·
分配同工 · 分配同工邮箱 · 分配日期 · 末次联系结果 · 末次联系日期 · 升级通知已发 · 备注

> 带「访客ID / 分配… / 末次… / 升级…」等由系统自动填写，人工只需填前面几项。
> `访客ID` 建议随手填一个唯一值（如 001、002），系统用它关联反馈。

## 五、隐私说明

访客个人信息（姓名、电话）只存在你的 Google 表格里，**不在本代码仓库中**。
本文件夹只是代码备份，不含任何个人数据。
